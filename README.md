# Hi, I'm Idrees

I'm a Computer Engineering student working on machine learning. My research explores LLM evaluation, learning from simulated data, and financial forecasting.

## Things I've built

- **[Market Decompression](https://github.com/idreesaziz/market-decompression)** — experiments on learning from simulated markets when real training data is scarce. This repository contains an earlier version; the [current paper](https://doi.org/10.5281/zenodo.23377391) was accepted after peer review at ACM ICAIF 2026.
- **[No One Gets an A](https://github.com/idreesaziz/Distributional-Bias-in-LLM-Text-Scoring)** — text degradation, LLM scoring, and analysis pipelines. First-author research with Mahir Sadikhov.
- **[AgentTrace](https://github.com/idreesaziz/agent-trace)** — a local debugger for agent workflows, with a Python SDK and a React/TypeScript interface.
- **[Sycophantic AI Benchmark](https://github.com/idreesaziz/sycophantic-ai-benchmark)** — a pilot benchmark for studying how model responses change under repeated pushback.

My [prediction-market research](https://doi.org/10.5281/zenodo.23377346) and [FinEntropyBench](https://doi.org/10.5281/zenodo.23377381) were accepted after peer review for oral presentation at **ACM ICAIF 2026**. The linked versions are preprints; proceedings are forthcoming.
